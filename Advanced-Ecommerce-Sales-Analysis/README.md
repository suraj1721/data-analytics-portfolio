# Advanced E-commerce Sales & Profitability Analysis

## Project Overview
This project analyzes 1,000 synthetic e-commerce transactions using Microsoft Excel to understand sales performance, profitability, and customer behaviour.

## Tools Used
- Microsoft Excel
- Advanced Excel Formulas
- PivotTables
- PivotCharts
- Power Query
- Data Visualization

## Key Performance Indicators
- Total Net Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value

## Analysis Performed
1. Monthly Sales Analysis
2. Regional Sales Performance
3. Product Profitability
4. Customer Analysis
5. Data Quality Checks

## Dataset
The dataset contains 1,000 fictional transactions created for educational purposes.
